# Unity Estimating — Frontend

Next.js frontend inspired by [unityestimating.com](https://www.unityestimating.com/).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home (hero, booking form, services, trades, testimonials)
- `/services` — Services & takeoffs
- `/estimating-fee` — Pricing packages
- `/about` — About / how we work
- `/contact` — Contact form

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Lucide icons
